# 课表识别助手（TimetableOCR）

从 **PDF** 或 **Excel** 课表文件自动识别课程信息，并导出为 Excel 课表、JSON 或可导入日历的 **ICS** 文件。

- 技术栈：Python + PyQt5
- 扫描版 PDF 使用 **Windows 内置 OCR**（无需额外安装识别引擎）
- 支持复杂版式：一格多课、合并单元格、跨页断单元格、多工作表、无表头工作表、单双周

项目仓库：<https://github.com/ChenTom233/Course-OCR-manage-tools>

---

## 功能特性

- **输入**：`.pdf`（含文本层课表，以及扫描件的 OCR 兜底）、`.xlsx` / `.xlsm` / `.xls`
- **版式**：网格课表（行=节次、列=星期）、列表课表（每行一门课）、合并单元格、多工作表
- **字段**：课程名称、星期、节次、周次（含单双周、离散周）、教师、教室、具体时间
- **多工作表选择**：导入含多个工作表的 Excel 时，可勾选要导入哪些表
- **班次筛选**：识别出多个「教学班」时，弹窗选择要保留的班次
- **作息时间设置**：自定义每节课的开始时间与时长
- **课程编辑**：双击/按钮新增、编辑、删除课程
- **时间冲突检测**：识别出同一时段有多门课时，自动高亮并弹窗提醒
- **导出**：Excel（课表网格 + 课程列表两张表）、JSON、ICS 日历（可选提前提醒）
- **崩溃日志**：程序异常时自动记录，便于排查问题

## 快速开始

### 方式一：使用打包好的程序（推荐）

1. 解压发布包（如 `TimetableOCR-vX.X.X-win64.zip`）。
2. 双击 `TimetableOCR.exe`（或 `课表识别.exe`）即可运行，无需安装 Python。
3. 注意：exe 必须和 `_internal` 文件夹放在同一目录，不要只拷贝 exe 本体。

> 若使用扫描版 PDF，请先确保系统安装了中文 OCR 语言包（见下方「常见问题」）。

### 方式二：从源码运行

需要 Python 3.10+（Windows）。

```bash
pip install -r requirements.txt
python main.py
```

## 使用说明

### 1. 添加文件

点击「**添加文件**」按钮（或快捷键 `Ctrl+O`），选择 PDF 或 Excel 课表文件，可一次选多个。

### 2. 选择工作表（仅多工作表 Excel）

如果某个 Excel 里有**多个工作表**，点击「开始识别」后会弹出「**选择工作表**」窗口：

- 默认全选，可「全选 / 全不选」，至少保留一个；
- 取消勾选的工作表会被跳过；
- 隐藏的工作表不会出现在列表里，也不会被识别。

### 3. 开始识别

点击「**开始识别**」按钮（或快捷键 `F5`）。识别过程在后台进行，进度显示在状态栏，详细过程写入「识别日志」。

### 4. 选择班次（仅识别到多个教学班时）

如果 Excel 最后一列是「教学班」且存在多个班次，识别完成后会弹出「**选择班次**」窗口，勾选要保留的班次即可。未标注班次的课程会始终保留。

### 5. 查看与修正

- **左侧「识别结果」表格**：列出所有课程（课程名称 / 星期 / 节次 / 周次 / 教师 / 教室）。
- **双击某行**可编辑该课程（也可用「编辑选中」按钮），修正识别错误。
- 可「新增课程」「删除选中」。
- **右侧「周课表预览」**：以网格形式查看一周课表，同一格多门课会纵向排列。
- **时间冲突提示**：如果两门课在同一星期、节次和周次重叠，会在识别结果里用**浅红色高亮**，并弹窗提醒，方便你删掉重复或冲突的课程。

### 6. 导出

顶部右侧「导出」区提供三种导出：

| 按钮 | 产物 | 说明 |
|------|------|------|
| **Excel** | `课表.xlsx` | 含「课表」网格 +「课程列表」两张工作表 |
| **JSON** | `课表.json` | 结构化数据，便于二次处理 |
| **日历 ICS** | `课程表.ics` | 导入系统日历 / Google / Outlook 等 |

导出前请确认顶部「**第 1 周周一**」的日期正确，它决定日历事件的开始日期。

### 7. 日历 ICS 与提醒

点击「**日历 ICS**」导出时，会先询问是否为每门课添加开始前提醒，可选：

- 不提醒
- 提前 5 / 10 / 15 / 30 分钟
- 提前 1 小时
- 提前 1 天

选择后，每个日历事件都会附带对应的提醒（`VALARM`）。将导出的 `.ics` 导入日历 App 即可看到课程日程。

### 8. 作息时间设置

点击「**作息时间**」按钮，可逐节设置每节课的**开始时间**和**时长**（结束时间自动计算，支持「恢复默认」）。修改后：

- 周课表预览的节次时间、Excel 导出的「时间」列、ICS 日历事件时间都会随之更新；
- 设置保存在 `%LOCALAPPDATA%\TimetableOCR\settings.ini`，重启程序也不会丢失。

## 常见问题

**Q1：扫描版 PDF 识别不出内容？**
扫描件依赖 Windows 自带的「中文 OCR」。请确认系统已安装中文 OCR 语言包：
设置 → 时间和语言 → 语言 → 添加「中文（简体）」，并勾选/安装其 OCR（手写）组件。

**Q2：导入日历后课程时间错乱或重叠？**
- 时间错乱：确认顶部「第 1 周周一」填的是学期第一周**周一**的日期（不是开课日、也不是今天）。
- 课程重叠：课表本身可能包含多个平行班（不同班同一时段上课）。识别后可用「选择班次」只保留自己要的班次；或在结果里删掉不需要的课程。

**Q3：识别结果有误怎么办？**
双击对应课程直接修正；也可以把样例文件反馈给开发者调整解析规则。

**Q4：程序崩溃了，日志在哪？**
- Python 异常日志：`%LOCALAPPDATA%\TimetableOCR\logs\crash.log`
- 原生崩溃日志：同目录下的 `native.log`（其中 `0x8001010d` 是 Windows/Qt 的良性 COM 异常，可忽略）

**Q5：`.xls`（旧版 Excel）无法解析？**
源码运行需安装 `xlrd`（`requirements.txt` 已包含）；打包版已内置。

## 从源码打包

```bash
python -m PyInstaller --noconfirm --clean TimetableOCR.spec
```

产物在 `dist/TimetableOCR/`（onedir 模式，入口 `TimetableOCR.exe`）。发布时把该目录下的内容压成 zip 即可。

> 打包体积已做过裁剪：排除了 RapidOCR（onnxruntime/numpy/cv2）、Qt Quick/QML、软件 OpenGL、Qt 翻译文件、未用到的图片插件等，解压后约 78 MB。

## 目录结构

```
.
├── app/
│   ├── gui.py           # PyQt5 图形界面

│   ├── parsing.py       # 通用解析逻辑（网格/列表/周次等）
│   ├── ocr.py           # OCR 后端（Windows 内置 OCR，RapidOCR 可选回退）
│   ├── exporters.py     # Excel / JSON / ICS 导出
│   ├── models.py        # 数据模型
│   ├── settings.py      # 作息时间持久化
│   └── crashlog.py      # 崩溃日志
├── main.py              # 程序入口
├── requirements.txt     # 依赖
├── TimetableOCR.spec    # PyInstaller 打包配置
└── LICENSE
```
